# 信用评分专家经验（能力抽取源 · 模拟业务材料）

> 本文件为本项目构造的模拟业务材料，用于演示从「专家经验」抽取特征工程与模型选择能力。
> 经验条目为教学性构造，不代表任何机构真实策略。

## 1. 预处理经验

| 编号 | 经验 | 原因 |
|---|---|---|
| E1 | `EDUCATION` 的 0/5/6、`MARRIAGE` 的 0 统一归入「其他」 | 数据字典未定义，直接 One-Hot 会引入稀疏噪声或触发未知类别报错 |
| E2 | `PAY_*` 的 -2 保留为独立类别，不裁剪为 0 | -2 表示无消费记录，与按时还款（-1）语义不同 |
| E3 | `BILL_AMT*` 负值保留符号 | 负值代表退款/多付，取绝对值会丢失信息 |
| E4 | 所有预处理器置于 `sklearn.Pipeline` 内并仅在训练集 fit | 防止均值/编码统计量泄漏到验证集 |

## 2. 特征工程经验

| 编号 | 经验 | 派生方式 |
|---|---|---|
| E5 | 连续逾期月数是最强单一信号 | 统计 `PAY_0`、`PAY_2`…`PAY_6` 中 > 0 的期数 |
| E6 | 最大逾期等级 | `max(PAY_0, PAY_2, …, PAY_6)` |
| E7 | 还款率需按期次对齐 | `PAY_AMT2 / BILL_AMT1`（9 月实付针对 8 月账单），分母为 0 时置 0 |
| E8 | 账单趋势 | `BILL_AMT1 - BILL_AMT6`、`BILL_AMT*` 均值与标准差 |
| E9 | 额度使用率 | `BILL_AMT1 / LIMIT_BAL`，`LIMIT_BAL = 0` 时置 0 |

## 3. WOE 分箱与评分卡

| 编号 | 经验 |
|---|---|
| E10 | 对 `LIMIT_BAL`、`AGE`、`BILL_AMT1` 做监督分箱（5–10 箱），计算 WOE 与 IV，IV < 0.02 的变量剔除 |
| E11 | WOE 变换后接逻辑回归，可输出标准评分卡分数，可解释性优于树模型，适合作为 baseline 候选 |
| E12 | 分箱边界必须在训练集内学习，验证/测试集只做 apply |

## 4. 模型选择经验

| 编号 | 经验 | 适用条件 |
|---|---|---|
| E13 | 逻辑回归 + WOE | 需要可解释、需输出评分卡、样本量小 |
| E14 | 随机森林 | 存在非线性交互，允许黑箱，需 `class_weight='balanced'` |
| E15 | HistGradientBoosting | 追求 AUC/KS 上限，注意限制 `max_iter` 以满足 60s 时限 |
| E16 | SMOTE | 仅对训练集过采样，绝不能对全量数据采样；与 `class_weight` 二选一 |
| E17 | 阈值 | 按 5:1 成本比在验证集网格搜索，不在测试集调阈值 |

## 5. 依赖与顺序约束

推荐 pipeline 顺序（对应知识图谱的 `PRECEDES` 边）：

```
列名映射 → 类别清洗 → 特征派生 → WOE/编码 → 采样 → 模型 → 阈值
            ↑ 全部在训练集 fit，验证/测试集仅 transform
```
