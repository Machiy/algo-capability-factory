# 历史实验记录（能力抽取源 · 模拟业务材料）

> 本文件为本项目构造的模拟业务材料。表中指标为**构造的历史记录**，仅用于演示「从实验记录抽取模型选择经验与历史验证结果」，不是本项目的实测结果。

## 实验环境与口径

- 固定随机种子 42；时间外划分 train 60% / valid 20% / test 20%；test 仅终评一次。
- 指标：AUC、KS、PR-AUC、F1、成本加权损失（5:1）、单次训练耗时。

## 记录汇总

| 编号 | 模型 | 预处理 | 采样/阈值 | 验证集 AUC | 验证集 KS | 成本加权损失 | 耗时(s) | 结论 |
|---|---|---|---|---|---|---|---|---|
| EXP-01 | Dummy（分层随机） | 无 | 0.5 | 0.500 | 0.000 | 0.221 | 0.1 | 基线 |
| EXP-02 | LogisticRegression | 标准化 | 无 / 0.5 | 0.741 | 0.318 | 0.183 | 0.8 | 基线，未达 KS 门槛 |
| EXP-03 | LogisticRegression | WOE 分箱 | 无 / 0.5 | 0.772 | 0.361 | 0.171 | 2.4 | 可解释性好，KS 达标 |
| EXP-04 | LogisticRegression | WOE 分箱 | class_weight / 成本最优阈值 | 0.775 | 0.368 | 0.152 | 2.6 | 成本损失最低 |
| EXP-05 | RandomForest(200) | 类别编码 | class_weight / 0.5 | 0.779 | 0.372 | 0.168 | 6.1 | AUC 略高但成本损失不如 EXP-04 |
| EXP-06 | HistGB(max_iter=200) | 类别编码 | 无 / 0.5 | 0.783 | 0.381 | 0.165 | 4.3 | AUC/KS 最高 |
| EXP-07 | HistGB + SMOTE | 类别编码 | SMOTE / 0.5 | 0.770 | 0.355 | 0.176 | 7.9 | 过采样未带来收益，且耗时上升 |
| EXP-08 | HistGB(全量随机划分) | 类别编码 | 无 / 0.5 | 0.912 | 0.702 | 0.071 | 4.5 | **判定无效**：随机划分引入未来信息，指标虚高，已作废 |

## 可复用经验

| 编号 | 经验 | 来源 |
|---|---|---|
| K1 | WOE 分箱对逻辑回归的 KS 提升明显（0.318 → 0.361） | EXP-02 / EXP-03 |
| K2 | 按成本比调阈值比换模型更能降低业务损失 | EXP-04 |
| K3 | HistGB 在 AUC/KS 上最优，但可解释性弱于评分卡 | EXP-06 |
| K4 | SMOTE 在本数据集无收益，优先 `class_weight` | EXP-07 |
| K5 | 随机划分会造成严重虚高，必须时间外划分 | EXP-08（作废记录） |
| K6 | 训练耗时均低于 8s，满足 60s 时限；Beam Search 可行 | 全部 |

## 待验证问题

- PSI 群体稳定性在跨时段上的表现未测；
- `SEX` / `AGE` 分组 AUC 差异未纳入历史实验，需在本次原型中补齐。
