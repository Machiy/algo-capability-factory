# 短信数据集字典与已知问题（能力抽取源 · 模拟业务材料）

> 对应 `assets/data/sms_spam.csv`（UCI SMS Spam Collection，dataset 228，CC BY 4.0）。
> 只登记文本场景特有的数据问题，不写「已知数据问题」以外的章节，
> 避免抽取出与文本无关的表格数据集节点。

## 1. 字段定义

| 字段 | 类型 | 含义 |
|---|---|---|
| `text` | string | 短信正文，含大小写、标点、号码与 URL |
| `label` | int | 1 = spam，0 = ham（正常短信） |

## 2. 已知数据问题

| 编号 | 问题 | 处理方式 |
|---|---|---|
| ST1 | 大小写与标点不统一 | 统一小写后再做 TF-IDF，数字保留 |
| ST2 | 正文含电话号码与短链接 | 替换为 `phone` / `url` 占位符，避免记忆具体号码 |
| ST3 | 极短文本与重复文本 | 长度 < 3 的样本剔除；重复文本只在训练集保留一份 |
| ST4 | 标签分布偏斜 | spam 13.4%，评估用 macro-F1，必要时在 Pipeline 内做类别权重 |
