# 短信垃圾过滤 · 策略与适用条件（能力抽取源 · 模拟业务材料）

> 本文件为本项目构造的模拟业务材料，用于演示「换一个行业场景后，同一套抽取与检索仍然成立」。
> 结构与主场景的 `risk_policy.md` 一致：适用条件抽为 `Capability`，验收门槛抽为 `Metric`。

## 1. 业务目标

在短信下发前判断是否为垃圾/欺诈短信，用于运营侧拦截与人工复核排队。模型只输出概率与建议，不直接封号。

## 2. 适用条件（约束）

| 编号 | 约束 | 说明 |
|---|---|---|
| S1 | 文本长度 | 少于 3 个字符的样本不参与训练，避免噪声主导词表 |
| S2 | 语言范围 | 当前仅覆盖英文短信；中文短信需要另行分词，不能直接复用本词表 |
| S3 | 类别严重不平衡 | spam 约 13.4%，评估必须同时看 macro-F1，禁止只看 accuracy |
| S4 | 词表边界 | 向量器只能在训练集 fit，禁止在验证集 / 测试集上统计词表 |
| S5 | 号码与链接 | 电话、URL 用占位符替换，禁止让模型记住具体号码 |
| S6 | 判定阈值 | 默认 0.5；业务可通过调阈值控制误杀率，调阈只在验证集做 |

## 3. 验收门槛

| 指标 | 门槛 | 口径 |
|---|---|---|
| accuracy | 0.95 | 验证集，固定种子随机切分 |
| macro_f1 | 0.90 | 验证集，兼顾 spam 少数类 |

## 4. 与主场景的差异

表格分类可用列名与取值域做静态校验，文本场景没有列名可查，因此把校验重心放在「词表是否泄漏」与「少数类是否被误杀」两处。
