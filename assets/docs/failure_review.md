# 失败案例复盘（能力抽取源 · 模拟业务材料）

> 本文件为本项目构造的模拟业务材料，用于演示「自动分析失败案例并形成可复用经验」。
> 错误签名与修复策略将被抽取为 `FailureCase` 节点，供 Repairer 定向修复使用。

## FR-01 列名假设错误

| 项 | 内容 |
|---|---|
| 现象 | `KeyError: 'PAY_1'` |
| 根因 | 工程师按 `PAY_1`…`PAY_6` 的直觉命名编写代码，实际数据集最近一期列名为 `PAY_0`，不存在 `PAY_1` |
| 错误签名 | `KeyError: PAY_1` |
| 修复策略 | 按 `Dataset` 节点的列名映射表替换为 `PAY_0`、`PAY_2`…`PAY_6`；禁止按序号硬编码列名 |
| 可复用经验 | 使用数据字典校验列名，而非按业务直觉推断 |

## FR-02 未文档化类别导致编码失败

| 项 | 内容 |
|---|---|
| 现象 | OneHotEncoder 报未知类别 / schema 校验失败 |
| 根因 | `EDUCATION` 实测含 0/5/6（345 条），`MARRIAGE` 含 0（54 条），均不在数据字典枚举内 |
| 错误签名 | `SchemaError` |
| 修复策略 | 0/5/6 归入「其他」类别；`PAY_* = -2` 保留为独立类别；编码前做取值域校验 |
| 可复用经验 | 类别型特征的合法取值必须以数据实测为准，不能只信文档 |

## FR-03 数据泄漏导致指标虚高

| 项 | 内容 |
|---|---|
| 现象 | 验证 AUC 0.912，显著高于历史 0.78 量级；上线后效果骤降 |
| 根因 | ① 使用随机划分而非时间外划分；② 在全量数据上 fit 标准化/编码器；③ 使用了与目标同期的付款信息 |
| 错误签名 | `LeakageDetected` / `MetricSuspiciouslyHigh` |
| 修复策略 | 改时间外划分；强制 `sklearn.Pipeline` 且所有预处理器仅 on train fit；按 `PRECEDES` 约束检查期次 |
| 可复用经验 | 指标显著高于历史记录时，优先怀疑泄漏而非庆祝提升 |

## FR-04 阈值选择错误

| 项 | 内容 |
|---|---|
| 现象 | AUC 达标但业务损失偏高 |
| 根因 | 沿用 0.5 默认阈值，忽略 5:1 的漏报/误报成本比 |
| 错误签名 | `CostLossAboveBaseline` |
| 修复策略 | 在验证集上按成本加权损失网格搜索最优阈值，测试集不参与调阈 |
| 可复用经验 | 分类阈值是业务决策，不是超参数默认值 |

## FR-05 采样时机错误

| 项 | 内容 |
|---|---|
| 现象 | 验证指标虚高且不可复现 |
| 根因 | 对全量数据先做 SMOTE 再划分，合成样本跨训练/验证集 |
| 错误签名 | `LeakageDetected` |
| 修复策略 | 采样仅在训练集内、且在 Pipeline 内执行 |
| 可复用经验 | 任何改变样本分布的操作都必须在划分之后 |

## 错误签名 → 修复策略速查

| 签名 | 定向修复 |
|---|---|
| `KeyError: PAY_1` | 列名映射 |
| `SchemaError` | 类别归一化 + 取值域校验 |
| `LeakageDetected` | 时间外划分 + Pipeline 约束 |
| `MetricBelowThreshold` | 检索历史高分方案，切换模型族/采样/阈值 |
| `Timeout` | 降采样或换轻量模型 |
| `Nondeterminism` | 注入 `random_state` |
