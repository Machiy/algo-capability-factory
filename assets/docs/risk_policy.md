# 信用卡违约预测 · 风控策略与适用条件（能力抽取源 · 模拟业务材料）

> 本文件为本项目构造的模拟业务材料，用于演示从业务文档抽取「适用条件」与「评价指标」类能力。

## 1. 业务目标

在账单日出账前预测客户下月发生违约的概率，用于辅助额度管理与催收排期。模型仅作辅助决策，不单独触发拒贷或降额。

## 2. 适用条件（约束）

| 编号 | 约束 | 说明 |
|---|---|---|
| C1 | 客群范围 | 仅适用于持有 ≥6 期账单历史的存量客户；新客无 `PAY_*` / `BILL_AMT*` 序列，不在适用范围内 |
| C2 | 额度区间 | `LIMIT_BAL` 在本样本覆盖区间内；超出区间需人工复核 |
| C3 | 时间范围 | 训练样本观测期为 2005-04 至 2005-09；上线前须做 PSI 群体稳定性检查，PSI > 0.25 触发重训 |
| C4 | 划分方式 | 必须时间外划分，禁止随机打乱；所有预处理在训练集内 fit |
| C5 | 敏感字段 | `SEX` / `AGE` / `EDUCATION` / `MARRIAGE` 不得进入模型特征，仅用于分组公平性审计 |
| C6 | 标识字段 | `ID` 不得作为特征 |
| C7 | 可复现 | 固定随机种子 42，单次运行 60 秒内、内存 2GB 以内 |

## 3. 成本矩阵与阈值

| 真实情况 \ 预测 | 预测正常 | 预测违约 |
|---|---|---|
| 实际正常 | 0 | 1（误报：客户体验损失） |
| 实际违约 | **5**（漏报：坏账损失） | 0 |

- 漏报成本 : 误报成本 = **5 : 1**，因此默认 0.5 阈值不最优，须按成本加权损失网格搜索最优阈值；
- 指标优先级：`cost_weighted_loss` > `KS` > `AUC` > `F1`；
- 在准确率（accuracy）作为主指标会因 22.12% 的正例比例产生误判，本项目**不采用 accuracy 作为验收指标**。

## 4. 验收门槛（目标值，非实测结果）

| 指标 | 方向 | 门槛 |
|---|---|---|
| AUC | 越大越好 | ≥ 0.78 |
| KS | 越大越好 | ≥ 0.35 |
| PR-AUC | 越大越好 | ≥ 0.50 |
| 分组 AUC 差异 | 越小越好 | ≤ 0.10 |

同时要求优于两个基线：分层随机 Dummy、默认参数逻辑回归。

## 5. 依赖环境

Python 3.11+、pandas、scikit-learn、imbalanced-learn；纯 CPU；无需 GPU 与外部服务。
